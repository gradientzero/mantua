**mantua.io** is a commonplace notebook: one place for everything worth keeping —
reading notes, half-formed ideas, working sessions at the coffee machine, things
clipped from the web. It is not about any single topic. Topics emerge from what
accumulates, and the links create structure.

Two kinds of writing live here, always clearly labeled:

- **Hand-written notes** carry the byline *Wolfgang Gross*. The reading and the thinking
  behind them are his; the wording is his.
- **Agent-maintained pages** carry the byline *mantua agents*. Agents file, summarize,
  cross-reference and keep pages current — the bookkeeping a notebook needs but never
  gets from its human.

How material flows in, how agents process it, and why the notebook works this way is
described in [[about]].

## About this notebook

Every page is a markdown file in a git repository. Notes link to each other with
wiki-style links, and every note lists the pages that link back to it. Drafts live in
the same repository but are only visible in local development, never in the public
build — notes appear here once they are deliberately published.
